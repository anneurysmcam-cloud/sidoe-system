

Definicion y uso de cada una de las carpetas en este modelo. 

App = entrada y menú.
Data/Models = persistencia y lógica.
Features = cálculos.
Tracking = exportaciones.
Security = credenciales y auditoría.
Views = interfaz modular.
Utils = soporte.

Definicion y uso de cada uno de los archivos (modulos) en este modelo 

sidoe_system/
├── app.py                          # Punto de entrada principal (menú / router)
├── config.py                       # Configuración global
├── data/                                         
│   ├── database.py                 # Inicialización y conexión limpia a SQLite.
│   └── ETL_migracion.py            # Migración masiva histórica desde Excel/CSV hacia la BD.
├── models/                         
│   └── crud_indicadores.py         # Lógica CRUD (crear, leer, actualizar, eliminar indicadores).
│   └── logs.py                     # Registra constancia de cambios en indicadores para auditoría.
├── tracking/                       
│   ├── export_excel.py             # Convierte DataFrames a Excel en memoria.
│   └── export_pdf.py               # Exportación genérica a PDF (recibe datos y los transforma).
│   └── generar_ficha_pdf.py        # Da formato específico a la ficha PDF de un indicador.
├── features/                       
│   └── engine_factibilidad.py      # Motor que calcula factibilidad según umbrales oficiales.
├── security/
│   ├── auth.py                     # Login/logout y validación de credenciales.
│   ├── crear_admin.py              # Registro de acciones en tabla de auditoría.
├── views/                          
│   ├── crear_indicador.py          # Formulario para registrar indicadores.
│   ├── actualizar_indicador.py     # Edición y actualización de indicadores existentes.
│   ├── eliminar_indicador.py       # Eliminación segura con confirmación.
│   ├── consultas.py                # Búsquedas y consultas sobre la matriz.
│   ├── dashboard.py                # Tablero avanzado con visualizaciones (Plotly).
│   ├── admin_usuarios.py           # Gestión de usuarios administradores.
│   ├── ver_auditoria.py            # Visualización de registros de auditoría.
│   └── generar_ficha.py            # Vista para generar ficha PDF de un indicador.
└── utils/                  
    └── helpers.py                  # Funciones auxiliares reutilizables (ej. validaciones, formateo).

    A[app.py] --> B[views/]
    B --> B1[crear_indicador.py]
    B --> B2[actualizar_indicador.py]
    B --> B3[eliminar_indicador.py]
    B --> B4[consultas.py]

    B --> B6[admin_usuarios.py]
    B --> B7[ver_auditoria.py]
    B --> B8[generar_ficha.py]

    %% Conexión con modelos

    B2 --> C
    B3 --> C
    B4 --> C
    B5 --> C
    B8 --> D[tracking/generar_ficha_pdf.py]

    %% Exportaciones

    %% Motor de cálculo

    B5 --> E

    %% Seguridad

    B6 --> F1[security/crear_admin.py]

    H --> I[config.py]

    %% Utilidades
